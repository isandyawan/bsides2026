# Contributing to BSides & Security Research Compendium

First off, thank you for taking the time to contribute! Security research moves fast, and community-driven collections like this thrive on shared knowledge.

Please follow these guidelines to keep the compendium clean, organized, and valuable for everyone.

---

## 🚀 How to Add New Materials

1. **Fork** the repository and create your feature branch from `main` (e.g., `git checkout -b feature/add-bsides-melb-2026`).
2. **Locate the appropriate section** in the `README.md` file (e.g., Exploitation Research, CTF Challenges, Tooling, or Blogs).
3. **Add your resource** in alphabetical order using the established markdown format:
   ```markdown
   * **[Resource Name](URL)** - Brief, clear description of what the material covers.
